# Starbucks Loyalty Strategy Analytics Portfolio Project
**Target Role:** Data Analyst, Loyalty Strategy (Job ID: 260079240)
**Google Cloud Project ID:** `driiiportfolio`  

## Overview
Engineered to solve tier migration friction and premium product adoption challenges in the Seattle urban market for Starbucks Rewards. Conforms strictly to Google Cloud Free Tier cost governance.

## Quickstart
1. Run `src/generate_synthetic_data.py` in Colab.
2. Ingest CSVs into BigQuery (`driiiportfolio`).
3. Execute `sql/01_create_views.sql`.
4. Run `src/run_econometric_model.py`.
