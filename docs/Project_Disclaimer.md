# Project Disclaimer & Architecture Notice

## Synthetic Data Disclosure
The dataset utilized in this portfolio project is a synthetically generated simulation modeled on realistic quick-service restaurant (QSR) consumer behavior in Seattle, WA. It is designed specifically to test pipeline functionality and analytical architectures. No proprietary corporate data was utilized.
